# RainBox
Action-based blind hitboxes for Roblox. Server-sided, lag-compensated, rewindable, customizable, and built for fast-paced combat.

# FEATURESSS
- Lag compensation
- BLIND hitbox ( zero physics casting ONLY math )
- Custom character support
- Predictive interpolation between casting / ping
- Ping grouping
- Fully server-side yet matches the client
